<h2><a href="https://leetcode.com/problems/unique-length-3-palindromic-subsequences/"> 1930. Unique Length-3 Palindromic Subsequences </a></h2> <img src="https://img.shields.io/badge/Difficulty-Medium-orange" alt="Difficulty: Medium" /> <hr> <p> You are given a string <code>s</code> and must count how many <strong>distinct palindromic subsequences of length 3</strong> appear in it. A length-3 palindrome must look like <code>c x c</code> — the same character at both ends, and any character in the middle. Each resulting palindrome is counted once, even if it appears in multiple positions. </p> <h3>Example 1:</h3> <pre> <strong>Input:</strong> s = "aabca" <strong>Output:</strong> 3 <strong>Explanation:</strong> Valid unique subsequences are: - "aba" - "aaa" - "aca" </pre> <h3>Example 2:</h3> <pre> <strong>Input:</strong> s = "adc" <strong>Output:</strong> 0 <strong>Explanation:</strong> No character appears twice, so no length-3 palindrome exists. </pre> <h3>Example 3:</h3> <pre> <strong>Input:</strong> s = "bbcbaba" <strong>Output:</strong> 4 <strong>Explanation:</strong> Valid subsequences: - "bbb" - "bcb" - "bab" - "aba" </pre> <h3>Constraints:</h3> <ul> <li><code>1 ≤ s.length ≤ 1000</code></li> <li><code>s[i]</code> is a lowercase English letter</li> </ul> <hr> <h2>Approach</h2> <p> A palindrome of length 3 has the form <code>c _ c</code>. For each character <code>c</code> (from 'a' to 'z'): </p> <ul> <li>Find its first occurrence in the string</li> <li>Find its last occurrence</li> <li>If first &lt; last, then everything between them can act as the middle character</li> </ul> <p> The number of <strong>unique</strong> characters inside that range gives the count of unique palindromes starting and ending with <code>c</code>. Summing these counts for all characters gives the final result. </p>
